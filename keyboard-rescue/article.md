# 键盘坏了别急着换！我花 0 元，让 AI 把联想小新的键盘"救"了回来

> 趣味生活 · 省钱小妙招
>
> 一次真实的"AI 修电脑"记录：没拆机、没换键盘、没重装系统，省下几百块。

## 一、事情是这样的

我的笔记本是联想小新 Pro 13（2020 款），用了五年多，一直很稳。

直到某天，它开始"发疯"：

- 打着字，**"设置"窗口突然自己弹出来**，还总跑到最前面
- 有时候按一下 `i`，屏幕上刷出一长串 `iiiiiiiiii`
- 后来连 **Enter 键也失灵了**，发消息只能靠鼠标点发送按钮

第一反应：是不是键盘坏了？

去问维修，答复很统一：**"键盘和 C 面是一体的，要拆机整体换，几百块。"**

几百块不算多，但我不甘心——万一不是硬件问题呢？

于是我打开了 AI，开始了这场"不花钱的排查"。

## 二、三个最常见的误区

在讲怎么修之前，先说三个**看起来对、其实错**的判断：

**误区一：是输入法的问题**

很多人第一反应是"输入法抽风了"。但输入法再抽风，也不会让 `Win + I` 打开设置窗口。**这是系统快捷键，只有 Win 键参与才会触发。**

**误区二：重装系统就好了**

重装系统能解决 90% 的软件问题，但解决不了"某个键一直按着"这种信号层的问题。而且重装一次，环境和数据全得重来。

**误区三：键盘坏了就换键盘**

"按键失灵"分两种：**软件层误判** 和 **硬件层接触不良**。前者完全能软件修复，后者也未必需要马上换——可以用软件"绕过去"。

## 三、AI 是怎么查的：先取证，再结论

这台 AI 没有一上来就说"你键盘坏了"，而是做了五件事：

### 第 1 步：观察现象

先问清楚：什么时候发生？哪些键？有没有规律？

结果很关键：**只有打字时才触发，不碰键盘时一次都没有。**

### 第 2 步：量化测量

直接读系统的按键状态，连续采样：

```
检测项              结果
左 Win 键状态       300 / 300 次采样全部"按下"
右 Win / Shift / Ctrl / Alt   0 次异常
```

也就是说：**系统一直认为左 Win 键被按着**。

这一下就解释了"设置总弹出来"——按住 Win 再按 I，就是 `Win + I`，正好是打开设置。

### 第 3 步：排除软件干扰

- 卸载了 VMware 的输入注入驱动 → 问题依旧
- 检查键盘过滤驱动 → 只有系统自带的 `kbdclass`
- 检查键位映射 → 没有第三方改键

### 第 4 步：设计实验

发一个"松开"信号，观察状态变化：

```
发送前：按下
发送后 60ms：松开 ✅
```

这说明**硬件没有真的按住**，而是键盘"只发按下、不发松开"，系统以为它一直按着，于是自动连发。

### 第 5 步：得出阶段结论

> 键盘在打字时会丢失"松开"信号，属于**触点/薄膜老化**。不是病毒，不是输入法，也不是系统问题。

## 四、三招修复，全部 0 元

### 第 1 招：禁用"捣乱"的 Win 键

用 Windows 自带的**扫描码映射**，把左 Win 键直接屏蔽：

```
注册表位置：
HKLM\SYSTEM\CurrentControlSet\Control\Keyboard Layout
值名：Scancode Map
```

效果：**设置再也不弹了**，打字恢复正常。

### 第 2 招：吞掉"连发"

写了一个后台小守护，用键盘钩子监听：

- 同一个键，**120 毫秒内只认第一次**
- 卡键时最多多出一个字符，不会刷屏
- 正常打字完全不受影响

### 第 3 招：给 Enter 键"搬家"

Enter 彻底坏了，怎么办？

把**右 Ctrl 键**映射成 Enter：

```
右 Ctrl → Enter
```

右 Ctrl 平时几乎不用，位置又在键盘右下角，右手小指一伸就到。

**没有拆机，没有换键盘，三招全是软件。**

## 六、我把这套流程做成了一个开源工具

排查完我发现：**这套方法对很多人都有用**。于是把它整理成了一个单文件 PowerShell 脚本：

**KeyboardRescue · 键盘急救**

四个命令，覆盖 90% 的"键坏了"场景：

```powershell
# 1. 找出是哪个键在捣乱
.\keyboard-rescue.ps1 detect

# 2. 吞掉卡键连发（可开机自启）
.\keyboard-rescue.ps1 guard -Key I -Install

# 3. 把坏键的功能搬到备用键
.\keyboard-rescue.ps1 remap -Key RCTRL -To ENTER -Apply

# 4. 一键还原，什么都不留
.\keyboard-rescue.ps1 restore -Apply
```

特点：

- **单文件**，Windows 自带 PowerShell 就能跑，零依赖
- **默认只读**，不动手；加 `-Apply` 才真正执行
- **改之前自动备份**，一条命令还原
- **完全开源**，代码可审计，不联网

C 盘可用空间：**3.6 GB → 26.5 GB**。

## 八、最后，几句实在话

1. **软件修复 ≠ 根治**。我的键盘确实在老化，以后大概率还要换。这套工具是"撑到你有空换"的过渡方案。
2. **先取证，再动手**。别一上来就"一键优化""深度清理"，先看清楚问题在哪。
3. **可回滚比什么都重要**。任何改注册表的操作，先备份。
4. **AI 不是万能的**，但它能帮你把一个模糊的"电脑坏了"变成一条清晰的证据链。
